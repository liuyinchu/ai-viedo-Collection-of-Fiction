# 配乐方向 v3：贯穿全片

> 设计负责人 Claude 写给 Codex。导演已拍板：配乐改为贯穿全片，暂时继续用程序合成（2026-10-20）。
> 这份文件只定结构、对位和意图。音色和好不好听由导演判断；怎么合成由 Codex 决定。

## 为什么要改

v1、v2 只在三个窗口出现，加起来不到 1 分钟，其余两分多钟只有人声和空气。音量加大并不能改变"大部分时间是空的"。导演的反馈是"存在感太低"。

新原则：**音乐从头到尾都在，跟着故事起伏。人声永远清楚，停顿处要听得见音乐。**

## 动机

沿用 v2 的 D–A–E–B 主动机，它就是这部片子的"一句话"。全片围绕它变化：铺开、叠加、截断、换和声、最后再说一次。

## 和画面咬合

- 画面上的关键时刻要落在音乐的拍点上。`design/cues.json` 里，`settle` 提示点现在带了 `line` 字段（哪一行字凝结完成），可以挑这些作为音乐上的强拍：
  `s02`（开场那句）、`s03`（所有可能的句子）、`babel`（《巴别图书馆》）、`s07`（选出值得说的那一句）、`think`（思考，是忘记差异）、`s11b`（被压缩成了某种——）、`ma` / `maSig`（梅纳尔 A）、`mbSig`（梅纳尔 B 的署名）、`me1` / `me2`（两行"它们是我写的"）、`k1` / `k2` / `k3`（三个关键词）、`to`（收件人）、`card2`（先读）
- 其余的 `settle` 保留轻微的纸响，可以比现在更轻，避免和音乐打架
- `move` 提示点不用每个都配音乐，但镜头移动时音乐最好有流动感，不要停在一个和弦上不动

## 音量与混音意图

- 人声永远清楚，这一条不能让步
- 口播时音乐让开，但**不要让开到听不见**；段落间的停顿里，音乐要明显浮上来
- 三个高点（S05 末、S09 末、S19 拉远）明显高于其他段落；"塌缩"和"暗下去"要真的静
- 整体响度目标不变：−14 LUFS，真峰值 ≤ −1 dBTP

## 音色（程序合成）

建议的配器，Codex 可以调整，最终由导演听：
- **主动机**：沿用 v2 的琴音
- **底层**：低音区的持续声部，像弓弦乐器，用来托住全片，避免空
- **对位点**：很轻的铃或拨弦，只用在上面列出的强拍上

不要：鼓、节拍、合唱、科幻感的合成器嗡鸣、预告片式的爆发。

# 第三版画面计划：字成画

> 导演意见：第二版仍然太素，需要引入图和动画效果，而不只是文字（2026-10-20）。
> 核心做法：**墙上的字按图的明暗调整浓淡，组成一幅画。** 近看每一笔都是字，远看是一幅铜版画。
> 我只有字，但字可以组成画。这句话本身就是这期的主题，所以图像不是装饰。

## 动画手法

| 手法 | 效果 | 状态 |
|---|---|---|
| 字成画 | 画从字墙里一圈圈"长"出来：字先翻动，再变深、变大，锁成笔画 | 已做（迷宫样片） |
| 光标行走 | 光标沿着画里的路走，边走边写字 | 已做（迷宫样片） |
| 跟随的光 | 灯光跟着光标移动 | 已做 |
| 字的聚合与飞散 | 满墙的字飞起来聚成一句话；画溶解时字四散 | 待做 |
| 塌缩 | 整幅画向一点吸进去，只剩一行字 | 待做（第一版已有雏形） |
| 烛光闪动 | 富内斯的黑屋子里，光有轻微的呼吸 | 待做 |
| 前景视差、灰尘、景深 | 第二版样张已有 | 已做 |

## 每一段画什么

| 段 | 画（来源） | 怎么动 |
|---|---|---|
| 开场 S01–S02 | 小径分岔的花园：字组成的迷宫（程序生成） | 迷宫从光标四周长出来，镜头拉远；两个书名出现在两条岔路的尽头；光标选一条路走下去，写下"每次开口都是重新选一次" |
| 巴别 S03–S04 | 六边形回廊（P1，铜版画） | 移动落地时，回廊由字长出来，书架上一格格的书脊就是一行行字 |
| 巴别 S05–S06 | 天井（P2） | 拉远时，一层层回廊向下无限重复；S06 整幅画溶解，字四散回噪声 |
| 选择 S07 | 无图 | 满墙的字飞起来，只有一行被选中、落定：难的是，选出值得说的那一句 |
| 富内斯 S08–S09 | 那匹马（P3），转入黑屋子 | 烛光里，马由字长出来；细节一层层复制叠加，画越来越满 |
| 塌缩 S10 | — | 整幅画向中心吸进去，只剩"思考，是忘记差异" |
| 梅纳尔 S12–S14 | 骑士与侍从（P4） | A 处用旧书的宋体字组成，B 处用打字机一样的等宽字组成：**同一幅画，换一种字，就是另一幅画** |
| 总览 S16 | 全部 | 拉远看全墙：迷宫、回廊、马、骑士都在墙上，整面墙是一页带插图的书 |
| 收尾 S19 | 六边形回廊（P1） | 最后拉远：书页变成一本书，这本书放在六边形回廊的书架上 |
